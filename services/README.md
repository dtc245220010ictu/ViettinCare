# services/

Thư mục chứa lớp **nghiệp vụ (business logic)** của ứng dụng ViettinCare:

- `auth_service.py` - Xác thực và phân quyền người dùng (RBAC)
- `customer_service.py` - Quản lý hồ sơ khách hàng
- `ticket_service.py` - Quản lý vòng đời ticket hỗ trợ
- `ai_support_service.py` - Tính năng hỗ trợ AI (phân loại, gợi ý trả lời, tóm tắt...)
