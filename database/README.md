# database/

Thư mục chứa các tài nguyên liên quan đến **cơ sở dữ liệu** của hệ thống quản lý ticket ViettinCare.

- `schema.sql` - Định nghĩa cấu trúc bảng (CSDL SQLite mẫu).
- `db.py` - Module kết nối và khởi tạo cơ sở dữ liệu.
- `viettincare.db` - File cơ sở dữ liệu SQLite (được `.gitignore` bỏ qua khi ném lên Git).
