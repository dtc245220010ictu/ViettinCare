# templates/

Thư mục chứa các **mẫu giao diện HTML** (Jinja2 templates) của ứng dụng Flask:

- `base.html` - Mẫu cơ sở
- `login.html` - Trang đăng nhập
- `dashboard.html` - Trang điều khiển
- `tickets.html` / `ticket_detail.html` - Quản lý và chi tiết ticket
- `customers.html` - Quản lý khách hàng
